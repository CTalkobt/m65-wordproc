# tools/mkmsg.py makes of them build/writer.msg (WRITER.MSG on the disk:
# the strings one after another, each ended by a 0), which the BASIC

# free below the program: the graphics kernel's buffers, which Writer does

# program and the C half. Their numbers are their order here.
#

# the rest of it (BASIC: call sp(MSG_..., a$ + "," + b$); api.c's wp_say).
